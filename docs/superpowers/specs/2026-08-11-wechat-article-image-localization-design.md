# 公众号文章图片本地化设计

## 目标

公众号文章无论通过 Electron 登录渲染，还是普通 HTTP / Node.js 降级抓取，最终 Markdown 中的正文图片都应优先保存到 Obsidian 本地附件目录，手机端只要同步附件目录即可正常显示。

## 范围

- 仅修改 Obsidian 插件本地提取逻辑。
- 仅补齐普通公众号抓取路径；Electron 路径保持不变。
- 新文章生效，不迁移历史笔记。
- 不修改云函数、小程序、发布版本或线上数据。

## 行为

1. 普通抓取完成 HTML 转 Markdown 后，识别 Markdown 中的远程图片。
2. 下载成功时保存到 `网页图片/<日期>/`，并改写为 Obsidian 本地附件引用 `![[...]]`。
3. 公众号图片请求带文章 URL 作为 `Referer`，并带桌面浏览器 `User-Agent`，提高微信图片 CDN 下载成功率。
4. 单张图片下载失败时保留原远程图片 URL，不让整篇文章同步失败。
5. 在元数据中记录失败数量与精简错误，供诊断使用。

## 验收

- 普通公众号抓取路径能写入本地图片并输出本地附件引用。
- 图片下载失败时正文仍为成功，原图片 URL 保留，诊断包含失败数量。
- 非公众号网页行为不变。
- 构建产物与源码一致，现有插件回归通过。
