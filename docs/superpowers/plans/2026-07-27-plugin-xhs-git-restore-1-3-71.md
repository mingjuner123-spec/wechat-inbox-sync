# 小红书 1.3.30 公开图文语义恢复与 1.3.71 发布计划

## 目标

以 1.3.70 为不可回退基线，只恢复 1.3.30 已验证可用的小红书公开图文提取语义：

- 免费用户可保存公开返回的标题、正文、标签、封面和内页图。
- 不再因缺少唯一 noteId、通用网页标题、候选或推荐流标签而直接拒绝已有正文/图片。
- Pro 音视频转写、图片 OCR、评论区登录门槛、暂停转写删除、本地组件兼容等 1.3.70 能力不回退。

## 实现原则

1. `hasReadableXiaohongshuGraphicContent` 恢复 1.3.30 的内容判定：可信小红书页面中，有真实图片即可；无图片时正文至少 20 字。
2. 只保留两条质量底线：明确失效页拒绝；只有分享口令且没有真实图片的空页拒绝。
3. 不新增匿名候选身份、唯一候选、推荐流拒绝等复杂规则。
4. 无精确身份时不把不同浏览器页面任意拼接；只有相同非通用标题或共享真实图片时，才允许互补正文和图片。
5. 标记为音视频且仍是通用落地页时继续媒体探测，避免公开图文放宽后提前返回、跳过 Pro 转写。
