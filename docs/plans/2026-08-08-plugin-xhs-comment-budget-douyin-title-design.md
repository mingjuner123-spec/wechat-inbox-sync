# 小红书评论预算恢复与抖音标题去重设计

## 目标

- 小红书评论抓取总量从 1000 恢复为 300，保留既有 90 秒整体超时。
- 抖音详情只有 `desc`、没有独立标题时，不再把整段正文同时写入“标题”和“原文正文”。
- 不改变其他平台、云函数、用户绑定配置或本地组件。

## 实现

1. 将 `XIAOHONGSHU_TOTAL_COMMENT_LIMIT` 固定为 300；分页预算继续由该常量推导，整体超时继续为 90000ms。
2. 抖音标题优先使用独立 `title/preview_title`，其次使用与正文不同的页面标题；仍无标题时，从正文第一个非标签文本行生成不超过 80 字的标题。
3. 原文正文保持完整，标签继续独立输出。
4. 使用纯本地测试验证，不打开或登录小红书，不发起真实小红书请求。

## 验收

- 评论上限为 300、超时为 90 秒。
- 样例抖音正文的标题为“全平台内容，一键进 Obsidian”，且不等于完整正文。
- 插件核心、社媒输出、市场包和发布身份门禁通过。
